微信公众号 Markdown 排版常见问题

是否免费、怎么复制到公众号、支持哪些平台、主题和图片如何处理，集中说明如下。

什么是微信公众号 Markdown 排版工具？

它是一个免费的网页 Markdown 编辑器，地址是 https://wechat.jeffjade.com/。左侧写 Markdown，右侧预览微信公众号、知乎或掘金样式，然后一键复制到对应后台。

这个工具收费吗？需要注册吗？

不收费，也不强制注册。打开网站即可编辑、预览和复制。文稿默认保存在浏览器本地。

如何把 Markdown 复制到微信公众号？

打开编辑器，在左侧粘贴 Markdown，右侧确认样式后点击复制，再到微信公众号后台图文编辑器中粘贴。建议使用 Chrome、Arc 或 Edge。更细的步骤见 使用指南。

支持哪些平台？

主要支持微信公众号，同时提供知乎和稀土掘金的预览与复制。不同平台会过滤部分 HTML，粘贴后请检查代码块和图片。

可以自定义主题吗？

可以。顶部「主题」切换内置样式，「代码主题」切换代码高亮。也可以打开样式编辑区修改 CSS，预览会同步更新。

图片和公式怎么处理？

图片使用 ![说明](地址) 插入，可配置阿里云、七牛、Gitee 或 GitHub 图床。数学公式使用 $ 或 $$，预览后随正文复制。微信公众号对外部链接有限制，正文链接一般需为 mp.weixin.qq.com。

和 mdnice 是什么关系？

本站 fork 自开源项目 markdown-nice（常称 mdnice），由 nicejade（晚晴幽草轩） 维护，独立部署在 wechat.jeffjade.com。不是微信官方产品。

需要安装客户端吗？

不需要。它是纯网页应用，在桌面浏览器中使用即可。手机可以打开，但完整编辑体验按桌面浏览器设计。
