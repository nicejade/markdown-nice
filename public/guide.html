使用指南

如何用 Markdown 排版微信公众号文章

打开编辑器、写入 Markdown、预览主题、一键复制到公众号后台。全程在浏览器完成，大约三分钟。

这是做什么的？

公众号 Markdown 排版 是免费的网页编辑器。它把 Markdown 渲染成接近微信公众号的样式，让你在本地写完后直接粘贴到公众号后台，而不必在微信编辑器里反复调字体和间距。

打开编辑器 查看常见问题

操作步骤

  1. 打开工具。 使用 Chrome、Edge、Safari 或 Arc 访问 wechat.jeffjade.com。不需要账号。
  2. 撰写或粘贴 Markdown。 左侧是编辑区。可以从本地导入 .md 文件，也可以直接粘贴已有文稿。
  3. 预览效果并换主题。 右侧即时显示公众号样式。顶部菜单可切换主题、代码高亮，以及知乎、掘金预览。
  4. 复制并发布。 点击复制，打开微信公众号后台的图文消息编辑器，粘贴即可。公式和代码块会尽量保留。

微信公众号排版要注意什么？

  • 公众号正文链接通常只允许 https://mp.weixin.qq.com/ 域名。
  • 列表层级建议不超过两级，过深的嵌套在微信里容易错位。
  • 外链图片请先上传到可用图床，或使用工具内的图床配置。
  • 粘贴前用 Chrome 等现代浏览器复制，兼容性最好。

也能用于知乎和掘金吗？

可以。在预览区切换到知乎或掘金样式，再复制到对应编辑器。不同平台对 HTML 的过滤不同，复制后请再检查一遍标题、代码块和图片。
