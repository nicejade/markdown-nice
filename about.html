关于公众号 Markdown 排版

这是部署在 wechat.jeffjade.com 的免费网页工具，用来把 Markdown 排成微信公众号、知乎和掘金可用的样式。

谁在维护？

作者是 nicejade，内容站点为晚晴幽草轩。相关代码在 GitHub 开源。本工具不是微信、腾讯或知乎的官方产品。

和 markdown-nice 的关系

项目 fork 自开源编辑器 markdown-nice（社区常称 mdnice），在其 Markdown 渲染、主题和多平台复制能力之上独立部署与维护。上游项目见 mdnice/markdown-nice。

这个工具能做什么？

  • 用 Markdown 写公众号文章，实时预览近似微信的排版
  • 自定义主题和代码高亮，再一键复制到公众号后台
  • 切换知乎、稀土掘金预览并复制
  • 导入导出 Markdown，必要时导出 PDF
